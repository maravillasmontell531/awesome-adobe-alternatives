# Contribution Guidelines

- Add one tool per pull request, in the section it fits.
- Use the format `[Name](url) - Description.` Keep the description short and factual. End it with a period.
- The tool must work today and the link must load. Say whether it runs in the browser or on the desktop.
- State if it is open source, free, free with limits or paid.
- No duplicates. Search the list first.
